# Thèmes

Un thème est une **map Sass** (`configs/_<thème>.scss`) transformée en variables CSS déclarées sur `[data-product="<thème>"]`. Tous les thèmes déclarent les mêmes noms de variables, avec leurs propres valeurs : un composant qui utilise `var(--color-primary-default)` s'adapte automatiquement au thème actif.

## Nommage des variables

Le nom d'une variable est le chemin de la clé dans la map, joint par des tirets. Les valeurs pointent vers des primitives.

```scss
// configs/_edifice2d.scss
$edifice2d: (
  name: 'edifice2d',
  color: (
    buttons: (
      primary: (
        default: $yellow-400,
      ),
    ),
  ),
  radius: (
    button: $border-radius-pill,
  ),
);
```

```css
[data-product="edifice2d"] {
  --color-buttons-primary-default: #ffd357;
  --radius-button: 12.8rem;
}
```

Les variables de thème n'ont **pas de préfixe** : `--color-*`, `--font-*`, `--radius-*`. La clé `name` sert uniquement à identifier la map et n'est pas émise.

> Les tableaux ci-dessous sont **générés à partir du CSS chargé**, avec la valeur de chaque thème côte à côte.
