# Primitives

Les primitives sont les valeurs brutes du design system : palette de couleurs, espacements, rayons, typographie. Elles sont communes à tous les thèmes et émises une seule fois, sur `:root`, avec le préfixe **`--primitive-`**.

```css
:root {
  --primitive-grey-900: #383838;
  --primitive-spacer-16: 1.6rem;
  --primitive-border-radius-md: 0.8rem;
}
```

Elles viennent de deux fichiers, tous deux émis avec le même préfixe `--primitive-` :

| Fichier | Contenu |
| --- | --- |
| `configs/_primitives.scss` | Palette du nouveau design system, partagée par tous les thèmes |
| `configs/_primitives-legacy.scss` | Palettes historiques de neo et one, réservées à ces thèmes (et aux couleurs d'applications) |

Le nom CSS reprend le nom de la variable Sass : `$grey-900` → `--primitive-grey-900`, `$neo-orange-500` → `--primitive-neo-orange-500`.

> Les tableaux ci-dessous sont **générés à partir du CSS chargé** : ils reflètent toujours les valeurs synchronisées depuis Figma.
